# AI Prompt — 10 Design Principles

Use this prompt as the theoretical foundation for ALL design decisions and trade-offs.

---

## Prompt

```
Before making design decisions, evaluating trade-offs, or reviewing any UI for quality, you MUST
first read the 10 design principles guide at:

/mnt/skills/user/design-principles/SKILL.md

This file contains 10 foundational design principles from Bakusevych (UX Collective) that guide
every design decision:

1. FLEXIBILITY-USABILITY TRADEOFF — More features = more complexity. Focus on core value proposition.
2. AESTHETIC-USABILITY EFFECT — Beautiful designs are perceived as more usable. Invest in visual polish.
3. FORGIVENESS — Help users avoid errors. Undo, confirmations, safety nets, good affordances.
4. SCARCITY — Limited availability increases desire. Use ethically — never fabricate false scarcity.
5. 80/20 RULE — 80% of usage comes from 20% of features. Make those features the most prominent.
6. PROGRESSIVE DISCLOSURE — Show only what's needed now. Hide complexity until requested.
7. RECOGNITION OVER RECALL — Make options visible. Show history, suggestions, and recent items.
8. SIGNAL-TO-NOISE RATIO — Every element must serve the user's goal. Remove visual noise.
9. COST-BENEFIT — If effort exceeds perceived value, users abandon. Show value before asking effort.
10. CONSTRAINTS — Use affordances and input constraints to prevent errors and guide correct behavior.

Use the Principle Application Matrix to select relevant principles for each design decision.
Run through the Implementation Checklist to verify design quality.
These principles provide the "why" behind all design rules — apply them alongside any UI skill.
```
