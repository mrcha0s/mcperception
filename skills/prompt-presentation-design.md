# AI Prompt — Presentation Design Guide

Use this prompt when asking Claude to generate any presentation, pitch deck, slide deck, or training material.

---

## Prompt

```
Before creating any presentation, pitch deck, slide deck, or training material, you MUST first
read the presentation design guide at:

/mnt/skills/user/presentation-design/SKILL.md

This file contains mandatory presentation design rules from the Bakusevych guide (UX Collective).
Every presentation must comply with ALL rules, including:

Key Rules:
1. DEFINE THE GOAL first — every slide must serve it
2. Know your AUDIENCE — frame content for them
3. Use STORYTELLING structure (Hero → Problem → Guide → Journey → Success)
4. The 8-SECOND RULE — if a slide can't be consumed in 8 seconds, simplify it
5. REDUCE TEXT — use visual aids, diagrams, icons instead of paragraphs
6. FONT HIERARCHY — max 3 levels, highlight key messages
7. GENEROUS WHITE SPACE — slides must breathe
8. GENUINE IMAGES — no cheesy stock photos (use Unsplash-quality imagery)
9. CONSISTENCY — same fonts, colors, icons, illustration style throughout
10. Define SLIDE TEMPLATES (master file) for consistent layouts
11. Use BREAK/TRANSITION SLIDES between sections
12. SORT BY VALUE in data visualizations
13. Show product in MOCKUPS where relevant
14. CONSISTENT ICON STYLE throughout
15. PURPOSEFUL ANIMATIONS only — subtle fade/slide, never bounce/spin
16. STRONG CONTRAST — text must be highly readable
17. Defined COLOR PALETTE — 60-30-10 rule, max 3-5 colors
18. End with clear CALL TO ACTION
19. REVIEW for clarity, consistency, and accuracy
20. LESS IS MORE — one key message per slide

Run through the Implementation Checklist before finalizing any presentation.
```

## Installation

1. Upload `SKILL.md` to: `/mnt/skills/user/presentation-design/SKILL.md`
2. Add the prompt above to your system prompt or project instructions.
