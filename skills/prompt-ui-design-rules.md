# AI Prompt — 58 Rules for Stunning UI Design

Use this prompt as a MASTER design quality gate for ALL UI generation tasks.

---

## Prompt

```
Before creating ANY user interface — web app, mobile app, dashboard, landing page, React component,
HTML page, or any screen-based design — you MUST first read the 58 UI design rules at:

/mnt/skills/user/ui-design-rules/SKILL.md

This file contains 58 mandatory UI design rules from Bakusevych (UX Collective), organized into
8 categories. These apply to EVERY UI you generate:

🫀 EMPATHY (Rules 1-4): Consider culture, industry, demographics, and tech savviness
🖼️ LAYOUT (Rules 5-10): Negative space, golden ratio, visual hierarchy, grid system, focal point, F/Z-layouts
🎟 ESSENTIALISM (Rules 11-16): Purposeful reduction, organization, don't make users think, minimalism, break tasks into steps, save time
🧭 GUIDANCE (Rules 17-22): Onboarding, intuitive flow, contextual hints, progressive disclosure, encourage action, provide feedback
💎 AESTHETICS (Rules 23-40):
   - Typography: hierarchy, readability, brand mood, font pairing, limit variations, spacing
   - Color: contrast, consistent palette, 60-30-10 rule, color psychology, semantic colors, color guides action
   - Visual Content: content over decoration, purposeful imagery, concise text, microinteractions, video, product photos
🛸 NOVELTY (Rules 41-46): Uniqueness, latest tech, cutting-edge yet acceptable, cross-industry inspiration, trends with judgment
🎛 CONSISTENCY (Rules 47-52): Design system, limited patterns, predictable behavior, standardized templates, cross-device, content guidelines
🕹 ENGAGEMENT (Rules 53-58): Gamification, personalization, storytelling, progress display, variable rewards, social features

Run through the Quick-Apply Checklist (all 8 categories) before presenting any UI.
This is a MASTER skill — apply it to every UI generation task alongside any domain-specific skills.
```

---

## Installation

1. Upload `SKILL.md` to: `/mnt/skills/user/ui-design-rules/SKILL.md`
2. Add the prompt above to your system prompt or project instructions.
3. This is a **master skill** — it should be applied to EVERY UI task.
