Color Palette

7 hue families x 10 luminance steps + 2 anchors. Every color is WCAG AA verified. Monotonically decreasing luminance from step 50 (lightest) to step 900 (darkest).

72 Tokens AA Verified 7 Hues
QUICK START

<div class="bg-p-blue-500">...</div>

<!-- Text color -->
<p class="text-p-red-400">Error text</p>

<!-- Border -->
<div class="border border-p-neutral-700">...</div>

<!-- CSS variable -->
color: var(--color-p-teal-300);

1 Anchor Colors

Two special colors anchor the entire system. Pure #000000 is never used — the perceptual black is #0A0A0A.

2 Complete Palette

Each hue has 10 steps with monotonically decreasing luminance. Step 50 is near-white, step 900 is near-black. Click a hue to see detailed contrast ratios below.

3 Contrast Ratios

Select a hue to see every step's contrast ratio against White (#FFFFFF) and Black (#0A0A0A). Steps that pass AA small text (>= 4.5:1) are marked green, large text only (>= 3.0:1) in yellow, and failing in red.

4 Surface Mode Quick Reference

Which steps to use on each surface mode. These rules are universal across all 7 hues.

M1 — White Surface
Text: Steps 500-900
Accent: Step 500
Divider: Step 400
Avoid: Steps 50-300 for text
M2 — Black Surface
Text: Steps 50-400 + White
Accent: Step 400
Divider: Step 500
Avoid: Steps 600-900 for text
M3 — Light Hue (100)
Text: Steps 600-900 + Black
Accent: Step 600
Divider: Step 500
Avoid: Steps 50-300 for text
M4 — Dark Hue (800)
Text: Steps 50-300 + White
Accent: Step 300
Divider: Step 500
Avoid: Steps 600-900 for text
M5 — Mid Hue (500)
Text: White / Step 50
Accent: Step 50
Divider: Black
Avoid: Steps 300-700 for text
WCAG Thresholds
4.5:1 — AA small text
3.0:1 — AA large text / UI
<3.0:1 — Fails

7 Semantic Variables

When you set data-hue + data-mode on a container, these 13 semantic CSS variables resolve automatically.

<!-- All --p-* variables resolve inside this container -->
<div data-hue="blue" data-mode="2">
  <p style="color: var(--p-text)">Primary text</p>
  <p style="color: var(--p-accent)">Accent link</p>
  <hr style="border-color: var(--p-divider)" />
  <button style="background: var(--p-btn-bg); color: var(--p-btn-text)">Button</button>
</div>

8 Semantic Hue Mapping

Default hue assignments for semantic roles. Components can override via data-hue.

RoleHueSwatchUsage
Primary blue Default actions, links, primary buttons
Success green Confirmations, positive values, gains
Danger red Errors, destructive actions, losses
Warning yellow Caution, attention needed, pending
Info teal Informational, neutral notifications
Premium magenta Special features, premium tier, highlights
Default neutral Chrome, borders, secondary elements
