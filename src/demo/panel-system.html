Zero-Collision Guarantee
Every mode assigns distinct palette steps to these 6 roles: Page Background, Main Panel, Child Panel, Button Fill, Input Background, Panel Border. No two adjacent roles share the same step. Input background on main panel ≠ main panel background. Input background on child panel ≠ child panel background. Button fill ≠ any panel background. Button border ≠ any panel background. This is enforced by construction — not by accident.
