Depth Layers

On Mode 2 (Black) and Mode 4 (Dark Hue) surfaces, depth comes from a flat 4-layer brightness stack and 1px borders only. No gradients, no shadows, no bevels — just like a professional creative-tool panel.

Mode 2 Mode 4 Flat & 1px
THE THREE RULES
1. Every surface is a flat solid color. No linear-gradient(), no background-image.
2. Depth = brightness stacking. Closer surfaces are one palette step brighter; inset surfaces are one step darker.
3. Borders are 1px, always. Every interactive boundary gets a thin border — radius capped at 3px.

1 The 4-Layer Surface System

Depth is created by stacking four surface brightness levels, each exactly one palette step apart. Raised sits one step lighter than Panel; Input sits one step darker (pushed into the surface).

3 Border Tiers — All 1px

Every border is 1px solid. Three tiers of visibility carry meaning: Standard for interactive edges, Subtle for structural dividers, Focus for the active element.

MODE 2 — BLACK (NEUTRAL)

Subtle Panel edges, dividers, separators neutral.700

5 Forbidden vs Permitted

Mode 2 and Mode 4 override the base rules. These treatments do NOT apply to Modes 1, 3, and 5.

FORBIDDEN ON M2 / M4
  • × linear-gradient() / radial-gradient()
  • × box-shadow for depth or elevation
  • × text-shadow / filter: drop-shadow()
  • × opacity to mute colors — use a real palette step
  • × Border width > 1px (except 2px tab underline / card accent)
  • × Border-radius > 3px on controls
  • × Bold (600+) or uppercase button text
PERMITTED ON M2 / M4
  • ✓ Flat solid palette backgrounds (one hex value)
  • ✓ 1px solid borders — Standard / Subtle / Focus
  • ✓ box-shadow: 0 0 0 1.5px {focus} — focus ring only
  • ✓ border-bottom: 2px — active tab underline
  • ✓ border-left: 2px — card semantic accent
  • ✓ transition on state changes (0.1s ease)
  • ✓ SVG icons using the text / accent tokens
