Pagination

Surface-mode-aware page navigation. Connected link groups with 7 hues, 6 sizes, 5 surface modes. Active and disabled states with WCAG AA compliance.

Navigation WCAG AA 7 Hues 5 Modes
Quick Start
<!-- Basic pagination --> <nav aria-label="Page navigation"> <ul class="mc-pagination" data-hue="blue"> <li class="mc-page-item"><a class="mc-page-link" href="#">&laquo;</a></li> <li class="mc-page-item"><a class="mc-page-link" href="#">1</a></li> <li class="mc-page-item active"><a class="mc-page-link" href="#" aria-current="page">2</a></li> <li class="mc-page-item"><a class="mc-page-link" href="#">3</a></li> <li class="mc-page-item"><a class="mc-page-link" href="#">&raquo;</a></li> </ul> </nav> <!-- With surface mode context --> <div data-mode="1"> <nav aria-label="Page navigation"> <ul class="mc-pagination" data-hue="blue">...</ul> </nav> </div>
