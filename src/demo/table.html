Tables

Surface-mode-aware data tables. 7 hues, 5 modifiers, 6 sizes, 5 surface modes, sortable headers, semantic row colors.

.mc-table data-hue data-mode
Quick Start
<!-- Basic table --> <table class="mc-table" data-hue="blue"> <thead> <tr><th>#</th><th>Name</th><th>Status</th><th>Amount</th></tr> </thead> <tbody> <tr><td>1</td><td>Alice</td><td>Active</td><td>$1,200</td></tr> </tbody> </table> <!-- Striped + hover on dark surface --> <div data-mode="2"> <table class="mc-table mc-table-striped mc-table-hover" data-hue="blue">...</table> </div>

10 API Reference

Complete class and attribute reference.

Class / AttributeTypeDescription
mc-tableBaseRequired on every table element
data-hue="..."Attributeneutral | red | green | blue | yellow | magenta | teal
data-mode="..."Attribute1 | 2 | 3 | 4 | 5 (on ancestor container)
mc-table-stripedModifierAlternating row backgrounds
mc-table-striped-columnsModifierAlternating column backgrounds
mc-table-hoverModifierHighlight rows on hover
mc-table-borderedModifierBorders on all cells
mc-table-borderlessModifierRemove all borders
mc-table-xsSize11px font, compact padding
mc-table-smSize12px font, small padding
md (default)Size14px font, standard padding
mc-table-lgSize16px font, large padding
mc-table-xlSize18px font, extra-large padding
mc-table-xxlSize20px font, max padding
mc-table-activeRow stateHighlight selected row (on <tr>)
mc-table-row-{hue}Row colorSemantic row coloring: red, green, blue, yellow, magenta, teal
mc-table-sortableFeatureEnables sortable header styling (on table)
mc-table-sort-ascSort stateAscending sort indicator (on <th>)
mc-table-sort-descSort stateDescending sort indicator (on <th>)
mc-table-responsiveWrapperHorizontal scroll wrapper (on parent div)
mc-table-caption-topFeatureMove caption above table (on table)
mc-table-group-dividerFeatureThicker border between tbody groups (on tbody)
