Typography Text Tiers

Surface-mode-aware text colors — 3 neutral tiers + 3 hue tiers per mode, all WCAG AA ≥ 4.5:1

How It Works

Each data-hue + data-mode surface block defines 6 text color CSS variables. Use the utility classes inside any surface container — colors auto-adapt to guarantee WCAG AA contrast.

Neutral Tiers

.mc-text-n1 — Primary (headings, key text)
.mc-text-n2 — Secondary (body, descriptions)
.mc-text-n3 — Tertiary (captions, subtle)

Hue Tiers

.mc-text-h1 — Vivid hue (links, accents)
.mc-text-h2 — Medium hue (labels, tags)
.mc-text-h3 — Subtle hue (hints, borders)

Code Reference

<!-- Wrap content in a surface mode container -->
<div data-hue="blue" data-mode="2">
    <h2 class="mc-text-n1">Heading</h2>
    <p class="mc-text-n2">Body text</p>
    <span class="mc-text-n3">Caption</span>

    <a class="mc-text-h1">Blue link</a>
    <span class="mc-text-h2">Blue label</span>
    <span class="mc-text-h3">Blue hint</span>
</div>

<!-- CSS variables available inside any surface block -->
.custom-element {
    color: var(--p-text-n1);     /* primary neutral */
    border-color: var(--p-text-h3);  /* subtle hue */
}
