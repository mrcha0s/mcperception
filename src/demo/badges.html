Badge

Surface-mode-aware inline labels, tags, and status indicators. 7 hues, 4 variants, 6 sizes, 5 surface modes.

New API WCAG AA 7 Hues 5 Modes
Quick Start
<!-- Basic usage --> <span class="mc-badge mc-badge-filled" data-hue="green">Active</span> <!-- With size + shape --> <span class="mc-badge mc-badge-outline mc-badge-lg mc-badge-pill" data-hue="blue">Beta</span> <!-- Surface mode adaptation (inherits from parent) --> <div data-hue="neutral" data-mode="1"> <!-- white surface --> <span class="mc-badge mc-badge-outline" data-hue="red">Error</span> </div>
