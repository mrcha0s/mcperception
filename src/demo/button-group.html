Button Group

Group buttons into connected toolbars and segmented controls. Horizontal, vertical, and toolbar layouts with 7 hues, 6 sizes, and 5 surface modes. WCAG AA compliant.

Layout WCAG AA 7 Hues 5 Modes
Quick Start
<!-- Horizontal button group --> <div class="mc-btn-group" role="group" aria-label="Basic button group"> <button class="mc-btn" data-hue="blue">Left</button> <button class="mc-btn" data-hue="blue">Middle</button> <button class="mc-btn" data-hue="blue">Right</button> </div>

1 Basic Button Group

Horizontal group of connected solid buttons on Mode 2 (dark). Adjacent buttons share borders with inner border-radius removed.

Blue — Mode 2 (default dark)
Code
<div class="mc-btn-group" role="group" aria-label="Basic button group"> <button class="mc-btn" data-hue="blue">Left</button> <button class="mc-btn" data-hue="blue">Middle</button> <button class="mc-btn" data-hue="blue">Right</button> </div>

2 Outlined Group

Button group using outlined variants. The border-collapse ensures clean shared edges between buttons.

Blue outlined — Mode 2
Green outlined — Mode 2
Code
<div class="mc-btn-group" role="group" aria-label="Outlined button group"> <button class="mc-btn mc-btn-outline" data-hue="blue">Left</button> <button class="mc-btn mc-btn-outline" data-hue="blue">Middle</button> <button class="mc-btn mc-btn-outline" data-hue="blue">Right</button> </div>

3 Mixed Styles

Button groups can mix different hues on each button, allowing for multi-purpose action bars.

Mixed hues — solid
Mixed hues — outlined
Code
<!-- Mixed hues — each button has its own data-hue --> <div class="mc-btn-group" role="group" aria-label="Actions"> <button class="mc-btn" data-hue="green">Approve</button> <button class="mc-btn" data-hue="yellow">Review</button> <button class="mc-btn" data-hue="red">Reject</button> </div>

4 Button Toolbar

Combine multiple button groups and input groups into a toolbar using .mc-btn-toolbar. The toolbar provides flex layout with consistent spacing.

Toolbar with multiple groups
Toolbar with input group
Code
<div class="mc-btn-toolbar" role="toolbar" aria-label="Toolbar"> <div class="mc-btn-group" role="group" aria-label="First group"> <button class="mc-btn" data-hue="blue">1</button> <button class="mc-btn" data-hue="blue">2</button> <button class="mc-btn" data-hue="blue">3</button> </div> <div class="mc-btn-group" role="group" aria-label="Second group"> <button class="mc-btn mc-btn-outline" data-hue="teal">5</button> <button class="mc-btn mc-btn-outline" data-hue="teal">6</button> </div> </div>

5 Size Scale

All 6 sizes from xs (11px) to xxl (20px). The size class on the group overrides child button sizing for uniform groups.

xs
sm
md
lg
xl
xxl
Code
<!-- Extra small --> <div class="mc-btn-group mc-btn-group-xs" role="group">...</div> <!-- Small --> <div class="mc-btn-group mc-btn-group-sm" role="group">...</div> <!-- Medium (default — no size class needed) --> <div class="mc-btn-group" role="group">...</div> <!-- Large --> <div class="mc-btn-group mc-btn-group-lg" role="group">...</div> <!-- Extra large --> <div class="mc-btn-group mc-btn-group-xl" role="group">...</div> <!-- Extra extra large --> <div class="mc-btn-group mc-btn-group-xxl" role="group">...</div>

6 Vertical

Stack buttons vertically with .mc-btn-group-vertical. Adjacent buttons share horizontal borders with top/bottom radius removed.

Solid — blue
Outlined — teal
Mixed hues
Code
<div class="mc-btn-group-vertical" role="group" aria-label="Vertical group"> <button class="mc-btn" data-hue="blue">Top</button> <button class="mc-btn" data-hue="blue">Middle</button> <button class="mc-btn" data-hue="blue">Bottom</button> <button class="mc-btn" data-hue="blue">Last</button> </div>

7 Surface Modes

Button groups on all 5 surface modes. Child buttons inherit mode context from parent data-mode attribute. Shown with both solid and outlined variants.

Mode 1 — White (#FFFFFF)
Mode 2 — Black (#0A0A0A)
Mode 3 — Light Hue (blue.100 #dedeff)
Mode 4 — Dark Hue (blue.800 #000081)
Mode 5 — Mid Hue (blue.500 #5252ff)
