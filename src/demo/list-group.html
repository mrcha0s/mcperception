List Group

Flexible content lists with actionable items, active/disabled states, flush and numbered variants. 7 hues, 6 sizes, 5 surface modes with WCAG AA compliance.

Content WCAG AA 7 Hues 5 Modes
Quick Start
<!-- Basic list group --> <ul class="mc-list-group" data-hue="blue"> <li class="mc-list-group-item active">Active item</li> <li class="mc-list-group-item">Second item</li> <li class="mc-list-group-item">Third item</li> <li class="mc-list-group-item disabled">Disabled item</li> </ul> <!-- With surface mode context --> <div data-mode="1"> <ul class="mc-list-group" data-hue="blue">...</ul> </div>

2 Actionable Items

Anchor links (a)
Active link item Second link item Third link item Disabled link item
Button elements (button)
Code
<!-- Anchor-based actionable list --> <div class="mc-list-group" data-hue="blue"> <a href="#" class="mc-list-group-item mc-list-group-item-action active">Active link</a> <a href="#" class="mc-list-group-item mc-list-group-item-action">Link item</a> <a href="#" class="mc-list-group-item mc-list-group-item-action disabled" tabindex="-1" aria-disabled="true">Disabled link</a> </div> <!-- Button-based actionable list --> <div class="mc-list-group" data-hue="green"> <button type="button" class="mc-list-group-item mc-list-group-item-action active">Active button</button> <button type="button" class="mc-list-group-item mc-list-group-item-action">Button item</button> <button type="button" class="mc-list-group-item mc-list-group-item-action" disabled>Disabled</button> </div>

4 Flush & Numbered

Flush removes outer borders and rounded corners for edge-to-edge rendering. Numbered uses an ordered list with auto-numbering.

Flush (no border / no radius)
  • First flush item
  • Active flush item
  • Third flush item
  • Fourth flush item
  • Disabled flush item
Numbered (ol with auto-count)
  1. First numbered item
  2. Active numbered item
  3. Third numbered item
  4. Fourth numbered item
  5. Disabled numbered item
Code
<!-- Flush variant --> <ul class="mc-list-group mc-list-group-flush" data-hue="blue"> <li class="mc-list-group-item">Item text</li> </ul> <!-- Numbered variant --> <ol class="mc-list-group mc-list-group-numbered" data-hue="magenta"> <li class="mc-list-group-item">First numbered item</li> <li class="mc-list-group-item">Second numbered item</li> </ol>

8 Semantic Hue Mapping

Map hues to semantic meaning. Primary uses blue, success uses green, danger uses red, warning uses yellow, info uses teal, premium uses magenta.

Primary blue

Default navigation menus, standard list selections.

  • Dashboard
  • Settings
  • Profile
Success green

Completed items, verified entries, positive states.

  • Payment received
  • Order shipped
  • Delivery confirmed
Danger red

Error logs, alerts, flagged items, destructive actions.

  • Critical alert
  • Failed login attempt
  • Expired certificate
Warning yellow

Caution items, pending actions, attention needed.

  • Pending review
  • Low disk space
  • Update available
Info teal

Informational lists, neutral notifications, tips.

  • System status
  • Release notes
  • Documentation
Premium magenta

Special features, premium tier items, highlights.

  • Pro plan
  • Enterprise plan
  • Custom plan
Code
<!-- Primary navigation --> <ul class="mc-list-group" data-hue="blue">...</ul> <!-- Success / completed items --> <ul class="mc-list-group" data-hue="green">...</ul> <!-- Danger / error log --> <ul class="mc-list-group" data-hue="red">...</ul> <!-- Warning / pending actions --> <ul class="mc-list-group" data-hue="yellow">...</ul> <!-- Info / informational --> <ul class="mc-list-group" data-hue="teal">...</ul> <!-- Premium / special features --> <ul class="mc-list-group" data-hue="magenta">...</ul>
