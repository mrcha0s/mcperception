Breadcrumb

Navigation breadcrumbs showing the current page location within a hierarchy. 7 hues, 6 sizes, 5 surface modes, customizable dividers, and WCAG AA compliance.

Navigation WCAG AA 7 Hues 5 Modes
Quick Start
<nav aria-label="breadcrumb"> <ol class="mc-breadcrumb" data-hue="blue"> <li class="mc-breadcrumb-item"><a href="#">Home</a></li> <li class="mc-breadcrumb-item"><a href="#">Library</a></li> <li class="mc-breadcrumb-item active" aria-current="page">Data</li> </ol> </nav>

1 Basic Breadcrumb

Default breadcrumb on Mode 2 (dark), neutral hue. Three-level hierarchy: Home, Library, Data. The active item has no link and uses aria-current="page".

3 Custom Dividers

Override the default "/" divider using the --mc-breadcrumb-divider CSS custom property. Set it on the .mc-breadcrumb element.

/ (default)
  1. Home
  2. Library
  3. Data
> (chevron)
  1. Home
  2. Library
  3. Data
» (guillemet)
  1. Home
  2. Library
  3. Data
| (pipe)
  1. Home
  2. Library
  3. Data
- (dash)
  1. Home
  2. Library
  3. Data
Code
<!-- Default divider: / --> <ol class="mc-breadcrumb" data-hue="blue">...</ol> <!-- Chevron > --> <ol class="mc-breadcrumb" data-hue="blue" style="--mc-breadcrumb-divider: '>';">...</ol> <!-- Guillemet » --> <ol class="mc-breadcrumb" data-hue="blue" style="--mc-breadcrumb-divider: '\00bb';">...</ol> <!-- Pipe | --> <ol class="mc-breadcrumb" data-hue="blue" style="--mc-breadcrumb-divider: '|';">...</ol> <!-- Dash - --> <ol class="mc-breadcrumb" data-hue="blue" style="--mc-breadcrumb-divider: '-';">...</ol>
