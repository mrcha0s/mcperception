Radius & Rhythm

Corner radius scales with the size tier on light surfaces and caps flat on dark surfaces. Every dimension rides a strict 4px spacing rhythm — soft on light, sharp on dark.

6 Size Tiers 4px Base 3px Dark Cap
QUICK START
/* Light surfaces (M1 / M3 / M5) — radius scales with size */
border-radius: 4px; /* xs */
border-radius: 10px; /* xxl */

/* Dark surfaces (M2 / M4) — always cap at 3px */
border-radius: 3px;

/* Spacing — always a multiple of 4px */
gap: 16px; padding: 24px;

2 Corner Radius — Dark Surfaces (Mode 2 / Mode 4)

On dark surfaces the radius is capped flat at 3px for every size tier. Depth there comes from layered surfaces and 1px borders — never from rounding, gradients, or shadows. The two panels below contrast how the same scale resolves on light versus dark.

LIGHT — RADIUS SCALES 4 → 10px

Modes 1, 3, 5 — curve grows xs → xxl.

Mode 2 / Mode 4 — capped flat at 3px

Every tier holds at 3px. No gradients, no shadows, no bevels.

Do

Flat 3px corners and a 1px #515151 border on a dark panel. Depth reads from the layer + border alone.

Don't

Large soft corners on a dark control break the Photoshop-flat depth language. Never exceed 3px on M2 / M4.

3 Spacing — The 4px Rhythm

Every margin, padding, and gap is a multiple of 4px. Sticking to one base unit keeps vertical and horizontal spacing in lockstep across all 6 size tiers. Each bar below is drawn to its true pixel width.
