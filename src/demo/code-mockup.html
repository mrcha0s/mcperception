Code Mockup

Terminal-style code and command display blocks with prefix columns, status line highlights, and filled variants. 7 hues, 6 sizes, 5 surface modes, and WCAG AA compliance.

Display WCAG AA 7 Hues 5 Modes
Quick Start
<div class="mc-code-mockup" data-hue="blue"> <pre data-prefix="$"><code>npm install perception-bootstrap</code></pre> </div>

1 Basic Usage

A single-line terminal command using the data-prefix="$" attribute. The prefix column is automatically sized and separated from the code content.

Default (blue, Mode 2)
npm install perception-bootstrap
Code
<div class="mc-code-mockup" data-hue="blue"> <pre data-prefix="$"><code>npm install perception-bootstrap</code></pre> </div>

2 Terminal Output with Status Lines

Multi-line terminal output showing a command followed by warning and success status lines. Use .mc-code-mockup-line-warning, .mc-code-mockup-line-success, and .mc-code-mockup-line-error modifier classes on pre elements.

Multi-line with highlights (blue, Mode 2)
npm install perception-bootstrap
warn deprecated package@1.0
added 42 packages in 1.2s
Code
<div class="mc-code-mockup" data-hue="blue"> <pre data-prefix="$"><code>npm install perception-bootstrap</code></pre> <pre data-prefix=">" class="mc-code-mockup-line-warning"><code>warn deprecated package@1.0</code></pre> <pre data-prefix=">" class="mc-code-mockup-line-success"><code>added 42 packages in 1.2s</code></pre> </div>

3 Line Numbers with Error Highlight

Use numeric prefixes to display line numbers. Apply .mc-code-mockup-line-error to highlight a specific line — ideal for pointing out syntax errors or problematic code.

Numbered lines with error (blue, Mode 2)
function hello() {
  console.log("Hello");
  undefined.method(); // TypeError
}
Code
<div class="mc-code-mockup" data-hue="blue"> <pre data-prefix="1"><code>function hello() {</code></pre> <pre data-prefix="2"><code> console.log("Hello");</code></pre> <pre data-prefix="3" class="mc-code-mockup-line-error"><code> undefined.method(); // TypeError</code></pre> <pre data-prefix="4"><code>}</code></pre> </div>

4 Without Prefix

Omit the data-prefix attribute entirely for plain code display with no prefix column — useful for showing markup or multi-line snippets where the gutter would add noise.

No prefix (blue, Mode 2)
<div class="mc-code-mockup" data-hue="blue">
  <pre data-prefix="$"><code>...</code></pre>
</div>
Code
<!-- Omit data-prefix for no gutter column --> <div class="mc-code-mockup" data-hue="blue"> <pre><code><div class="mc-code-mockup" data-hue="blue"></code></pre> <pre><code> <pre data-prefix="$"><code>...</code></pre></code></pre> <pre><code></div></code></pre> </div>
