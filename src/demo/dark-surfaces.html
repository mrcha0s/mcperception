Dark Surface Depth

Photoshop-inspired flat layered depth system for Mode 2 (black) and Mode 4 (dark hue) surfaces.

1 Why Flat Design on Dark Surfaces

On dark backgrounds, gradients and box-shadows become invisible noise. They muddy the interface and destroy legibility. Professional creative tools like Photoshop, Figma, and VS Code achieve visual depth through a different mechanism: surface layering with flat solid colors and 1px borders only.

This approach gives dark interfaces a clean, precise, tool-like quality. Every element has a clear boundary. Every surface sits at a distinct brightness level. Depth is structural, not decorative.

Core Rules
No gradients
No box-shadows (except focus ring: 0 0 0 1.5px)
All backgrounds are flat solid palette colors
All borders are 1px solid
Border-radius max 3px on controls
Buttons: font-weight 400, sentence case

2 The 4-Layer System

Depth on dark surfaces is created by stacking 4 brightness levels. Each layer is exactly one palette step apart. Elements closer to the user are brighter; inset elements (inputs) are darker than the panel they sit on.

Layer Stack 
User's eye (closest)
    |
  Raised  (step 700)  -- brightest, closest to user
  Panel   (step 800)  -- standard working surface
  Deep    (step 900 or Black) -- page background, furthest away
  Input   (step 900)  -- pushed INTO the surface (darker than panel)

Mode 2 — Black Surface

Raised #373737 · neutral.700
Panel #222222 · neutral.800
Deep #0A0A0A · Black
Input #090909 · neutral.900

Mode 4 — Dark Hue (Blue example)

Raised #0000bf · blue.700
Panel #000081 · blue.800
Deep #000035 · blue.900
Input #000035 · blue.900
Usage
<!-- M2: Page background (Deep) --> <body style="background: #0A0A0A"> <!-- M2: Card (Panel) --> <div style="background: #222222; border: 1px solid #373737"> <!-- M2: Input (Input layer) --> <input style="background: #090909; border: 1px solid #373737" /> <!-- M2: Active tab (Raised) --> <div style="background: #373737">Active Tab</div> </div> </body>

4 Component Rules

Dark surface components follow strict rules that differ from Modes 1, 3, and 5. These ensure a clean, professional, tool-like appearance.

Buttons

Weight 400 (normal), sentence case, no uppercase, no bold, border-radius 3px max.

Do

1px border, weight 400, sentence case, radius 3px

Don't

Gradient, bold, uppercase, large radius, box-shadow

Inputs

Dark inset background (step 900), 1px border, no floating labels, no underline style.

Do

Label above, dark inset bg, 1px border, 2px radius

Don't
Email address

Floating label, underline style, transparent bg

Border Radius

Maximum 3px on all controls. Exceptions: circles for toggles, radios, and slider thumbs.

Do
Badge

Tight, square corners (2-3px)

Don't
Pill Badge

Rounded pill shapes on dark surfaces
