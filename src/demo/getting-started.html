Getting Started

Learn MC Perception in 5 minutes — from first button to full surface-mode-aware UI.

1 Installation

Add a single stylesheet to start building.

CDN Link
<link rel="stylesheet" href="mcperception.css">

No build tools required — just link the CSS and start building.

2 Your First Button

A single element with two classes and one data attribute.

Live Example
<button class="mc-button mc-button-filled" data-hue="blue">Click me</button>

mc-button is the base class, mc-button-filled sets the variant, and data-hue="blue" sets the color hue.

3 All 7 Hues

Every component supports 7 color hues for semantic meaning.

7 Hues
<button class="mc-button mc-button-filled" data-hue="neutral">Neutral</button> <button class="mc-button mc-button-filled" data-hue="red">Red</button> <button class="mc-button mc-button-filled" data-hue="green">Green</button> <button class="mc-button mc-button-filled" data-hue="blue">Blue</button> <button class="mc-button mc-button-filled" data-hue="yellow">Yellow</button> <button class="mc-button mc-button-filled" data-hue="magenta">Magenta</button> <button class="mc-button mc-button-filled" data-hue="teal">Teal</button>
Semantic Mapping
blue = Primary
green = Success
red = Danger
yellow = Warning
teal = Info
magenta = Premium
neutral = Default

4 Surface Modes

Components auto-adapt to 5 surface backgrounds. Same markup, different surface.

Mode 1 — White
Mode 2 — Black
Mode 3 — Light Hue (blue.100)
Mode 4 — Dark Hue (blue.800)
Mode 5 — Mid Hue (blue.500)
Code
<!-- Wrap components in a surface container with data-hue and data-mode --> <div data-hue="blue" data-mode="1"> <button class="mc-button mc-button-filled" data-hue="blue">Filled</button> </div> <!-- Change data-mode to switch surface — components auto-adapt --> <div data-hue="blue" data-mode="4"> <button class="mc-button mc-button-filled" data-hue="blue">Filled</button> </div>
